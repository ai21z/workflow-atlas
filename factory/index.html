From an idea to useful files
  1. Describe your work.
    Ask for a suggested workflow, review it and create a draft. You can also choose an investigation, feature or bug workflow yourself. Open a pack to continue.
  2. Adapt your workflow.
    Describe the outcome, select a stage and set its owner, skills and notes. Project details holds your brief, components, boundaries and sources.
  3. Inspect the files.
    Files shows the exact instructions. Preview Atlas gives you a readable view of the same decisions.
  4. Download and reopen.
    Choose a workflow blueprint, one focused skill or the full artifact pack. Follow its use guide. Every selected ZIP keeps your decisions and readable Atlas for reopening.
Where can I learn the concepts?
Knowledge map explains topics, examples and sources. It is the reference library. Your Workflow is the editable project, and Project Atlas is its readable snapshot.
What are skills, agents and evidence?
A skill describes a reusable procedure. An agent profile describes a role and requested tools. Evidence records an expected result and supplied observations. Generated instructions have not been run in your project.
How do I keep my work?
Project editing stays in this tab. Asking for a suggestion sends the displayed description and answers to TypeSafe through the local server. Download before closing or reloading. Open pack accepts an Atlas ZIP, project JSON, project HTML or a folder with Atlas metadata.
What if I edited the files elsewhere?
Opened files are retained alongside generated previews. Use Review file changes before replacing them, or download the opened files unchanged.
How can a reviewer understand my choices?
Preview Atlas begins with a decision brief. Read the wanted result, supplied approach notes, planned owners and open decisions. Technical details expand when needed.
How do I explain changes and check guidance?
Review changes compares recorded decisions with the session baseline or another supplied Atlas file. Add a reason and download ZIP or readable HTML to keep it with the exact baseline. Project JSON keeps settings only. Guidance and its limits shows source records, versions, scope and differences. Reviewing current guidance does not check upstream pages again or change opened files.
Keyboard and display controls
Use Tab to move, Enter or Space to activate, and Escape to close a panel or dialog. Select a role or skill, then a stage, as an alternative to dragging. Undo and redo are in the workspace toolbar. Theme changes apply to this session. Knowledge map includes topic navigation without the canvas.

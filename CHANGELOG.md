## 0.1.0-beta.1

First beta candidate. This entry does not announce a published release.

- Describe a task, review optional JEV suggestions and edit a supported workflow.
- Explore the Knowledge map and documentation without closing the project.
- Export a workflow blueprint, one focused skill or a full artifact pack.
- Reopen supported downloads and review changes while preserving external file edits.
- Keep incomplete facts visible and distinguish planned checks from observed results.
- Use light and dark themes in the editor, guides, map and portable Atlas.
- Keep JEV credentials on the local server, with manual mode available without a key.
- Build a separate static bundle and check it for credential patterns before distribution.
- Check app versions, documentation, generation and browser journeys in CI.

Public hosted JEV, workflow execution and verified behavior inside consumer hosts remain outside this beta.
